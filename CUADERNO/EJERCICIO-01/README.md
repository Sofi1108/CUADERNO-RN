# Ejercicio 01 - Mi primera pantalla

## Qué he aprendido

- Crear una pantalla con `View` y `Text`.
- Aplicar estilos con `StyleSheet`.
- Centrar contenido con Flexbox.

## Respuesta a la pregunta de comprensión

Explica con tus palabras la diferencia entre `View` y `Text`.

Respuesta: `View` es un contenedor visual que organiza otros elementos. `Text` sirve para mostrar texto en la pantalla.

## Qué he modificado

- He añadido una tercera línea con el texto `Curso 2026/27`.

## Resultado

La interfaz muestra un título, un subtítulo y el curso centrados en un fondo claro.
