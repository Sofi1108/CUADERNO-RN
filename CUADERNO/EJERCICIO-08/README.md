# Ejercicio 08 - Catálogo con FlatList

## Qué he aprendido

- Separar datos y presentación.
- Crear listas con `FlatList`.
- Usar `renderItem` y `keyExtractor`.

## Respuesta a la pregunta de comprensión

Si cambio un producto en el array, `FlatList` recibe los nuevos datos y vuelve a mostrar la tarjeta correspondiente. No tengo que buscar ni modificar manualmente el JSX repetido.

## Qué he modificado

- He añadido seis productos al array para formar el catálogo de dos columnas.

## Resultado

El catálogo genera automáticamente las tarjetas desde el array y muestra nombre, icono y precio.
