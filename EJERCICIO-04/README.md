# Ejercicio 04 - Pantalla de acceso

## Qué he aprendido

- Diseñar inputs.
- Representar un botón con `Pressable`.
- Diferenciar interfaz y lógica.

## Respuesta a la pregunta de comprensión

No necesitamos `useState` porque en este ejercicio solo practicamos el diseño visual del formulario y todavía no gestionamos los datos ni la validación.

## Qué he modificado

## Resultado

La pantalla contiene título, explicación, dos campos de entrada, contraseña protegida, botón y enlace visual de registro.
