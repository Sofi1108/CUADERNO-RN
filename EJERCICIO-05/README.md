# Ejercicio 05 - Tarjeta de producto

## Qué he aprendido

- Componer una tarjeta de producto.
- Usar `space-between`.
- Controlar el recorte visual con `overflow`.

## Respuesta a la pregunta de comprensión

El precio debe tener una jerarquía visual alta porque es un dato importante para decidir la compra. El nombre también destaca para identificar el producto y la categoría queda como información secundaria.

## Qué he modificado

- He añadido la etiqueta `OFERTA` antes del nombre del producto.

## Resultado

La tarjeta muestra imagen, categoría, oferta, nombre, valoración, precio y botón en una composición con esquinas redondeadas.
