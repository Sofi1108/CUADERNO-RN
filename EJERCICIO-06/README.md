# Ejercicio 06 - Dashboard de métricas

## Qué he aprendido

- Crear un grid con Flexbox.
- Usar `flexWrap`.
- Organizar métricas visuales.

## Respuesta a la pregunta de comprensión

Un ancho del 48% deja un pequeño espacio disponible para la separación entre tarjetas. Con un 50%, el `gap` podría hacer que no cupieran dos tarjetas en la misma fila.

## Qué he modificado

- He añadido una quinta tarjeta de tickets. Se coloca en la siguiente fila porque las dos primeras filas ya contienen dos tarjetas.

## Resultado

El dashboard muestra las métricas en tarjetas reutilizables, organizadas en dos columnas y con sus variaciones en verde.
